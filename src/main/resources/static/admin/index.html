Скаут-аккаунты

Что смотреть сейчас

  • Sidecar оффлайн → прокси и ЛС не работают.
  • Нет SENDER → рассылки в паузе.
  • FLOOD/BAN → SpamBot + смена прокси (автоматизируем дальше).
  • Живые диалоги — Кабинет TG (слева чаты, справа переписка).
  • Массовый join списком — вкладка ЦА / join.

Важно про прокси

  • Не крути прокси каждый день — у каждого скаута свой постоянный IP. Меняем только при FLOOD/бане.
  • «Проверить живые» — смотрит, отвечает ли порт. Это не 100% «ТГ не спалит», но отсекает дохлые.
  • Оба формата ок: ip:port:логин:пароль и логин:пароль@ip:port

Роли

  • PARSER / OBSERVER — ID 1–99 (короткие). Смотрят/парсят, ЛС не шлют. Если >99 → 1000+.
  • SENDER / OUTREACH — ID 100–999 (длинные). Только ЛС. Если >999 → 2000+. Старый #33 ок.
  • ACTIVE в БД ≠ в сети в Telegram. Старт не даст, пока нет сессии. Смотри бейдж «TG в сети / TG нет».
  • Карточка ≠ живой аккаунт. После создания: сессия → прокси → «Старт».

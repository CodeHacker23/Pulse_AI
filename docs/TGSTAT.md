# TGStat API — подключение и экономика

## Как подключить

1. Кабинет [api.tgstat.ru](https://api.tgstat.ru) → тариф **API Stat** (или выше с search).
2. Скопировать token.
3. В `application-local.yaml`:

```yaml
pulse:
  external:
    tgstat-token: "ВАШ_ТОКЕН"
```

либо env: `TGSTAT_TOKEN=...`

4. Рестарт `bootRun`. В логах при разборе: `Sync канал … через TGStat API`.

Без token Pulse живёт на скрейпе `t.me/s/` — «тонкая» статистика.  
С token: посты/охват/ERR/ИЦ + поиск площадок (`/channels/search`).

Важно: веб-подписка TGStat ≠ API. Нужен именно **API-токен** и доступ к методам search/stat/posts на тарифе.

## Почему «По запросу Pulse нет кандидатов»

Подбор площадок ищет по **нише (category)** канала.  
Если активный канал — продукт «Pulse…» и category пустая, в поиск уходит слово «Pulse» → пустота нормальная.

Нужно: разобрать канал **своей тематики** (чтобы записалась category) или вручную `@площадку` в «⋯ Ещё».

## Себестоимость ~2100 ₽/мес (ориентир API Stat)

| | |
|--|--|
| Пакет | ~2100 ₽ / 6000 запросов ≈ **0.35 ₽/вызов** |
| На 1 разбор канала | ~2–4 вызова (stat + posts ± search) ≈ **0.7–1.4 ₽** |
| LLM на разбор | **25–40 ₽** |
| **Итого COGS разбора** | **~26–42 ₽** |

6000 API-вызовов ≈ **1500–3000 разборов/мес** по TGStat-слою.  
Фикс 2100 ₽ окупается, если в месяце есть хотя бы **~80–100 платных запросов** при цене запроса **≥ 50–80 ₽** маржи сверх LLM  
(или меньше запросов, но дороже пакет).

Пример: пакет «Контент» 1600 ₽ / 18 запросов ≈ 89 ₽/запрос.  
COGS 35 ₽ → **~54 ₽** валовой маржи/запрос → **~970 ₽** с пакета.  
TGStat 2100 ₽ закрывается **~2–3 такими пакетами** (грубо), дальше маржа.

## Ценовая политика (рекомендация)

| Слой | Что отдаём | TGStat |
|------|------------|--------|
| **Бесплатно / вход** | Скрейп t.me: посты, просмотры «как смогли», идеи, черновики | **нет** |
| **Платный пакет (CONTENT+)** | ERR, ИЦ, охват, динамика, бенчмарк ниши, подбор площадок | **да** |
| **Опционально** | Отдельный perk «Глубокая статистика» / Pro | да |

Так фикс 2100 ₽ сидит в **платном топливе**, а не в каждом бесплатном клике.  
Квота 6000: резать search (площадки) и тяжёлые posts на платных; free — только scrape.

## Код (реализовано)

- `pulse.external.tgstat-paid-only: true` (default)
- `TgstatAccessService`: при `billing.enabled` TGStat только для **CONTENT/PRO** (покупка или perk CONTENT+)
- FREE / START → scrape `t.me`
- Локалка с `billing.enabled: false` → TGStat по token как раньше

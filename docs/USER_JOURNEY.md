# Pulse AI — Воронка пользователя (от /start до подписки)

> Живой документ. Описывает **как ведём пользователя** — не технические детали API.
> Смежные: [USER_FLOW.md](./USER_FLOW.md) · [PRODUCT_STATUS.md](./PRODUCT_STATUS.md) · [ROADMAP.md](./ROADMAP.md)

---

## Принцип UX

1. **Одна главная кнопка** внизу чата: `💡 Как это работает` — всё остальное через ссылку в поле ввода или inline после инструкции.
2. **Нет дублирования**: если инструкция уже говорит «пришлите ссылку», отдельная кнопка «Анализ канала» не нужна.
3. **Два типа канала** (важно объяснять пользователю):
   - **Любой открытый канал** — анализ по ссылке, права админа не нужны.
   - **Свой канал** — пересылка поста + бот админ → публикация черновиков.
4. **Мои отчёты** — список с названием канала и датой, кнопка «Открыть» → разбор + идеи.

## Этапы подробно

### Этап 0 — Первый контакт (`/start`)

| Что видит пользователь | Действие |
|------------------------|----------|
| Короткое приветствие: «пришлите ссылку на канал» | Одна кнопка: **Как это работает** |
| Reply-клавиатура | Только **Как это работает** (+ **Мои отчёты** после первого анализа) |

**Не показываем:** кнопку «Анализ канала», второе сообщение «Быстрые действия», дублирующие inline.

---

### Этап 1 — Онбординг («Как это работает»)

**Сообщение бота (структура):**

1. **Анализ** — пришлите `t.me/…` или `@username` любого открытого канала.
2. **Отчёт** — графики, разбор по секциям, идеи контента.
3. **Пост** — выберите идею → черновик → правка → публикация.
4. **Свой канал** — чтобы бот **постил за вас**: добавьте бота админом, перешлите пост из канала (кнопка «Подключить канал для публикации»).
5. **Пробный период** — бесплатно: 1 анализ, раздел «Главное» + «Идеи», 3 черновика поста.

**Кнопки под инструкцией:**
- `📢 Подключить свой канал` (только для публикации)
- `◀️ В меню`

После инструкции пользователь **интуитивно** шлёт ссылку — отдельная кнопка анализа не нужна.

---

### Этап 2 — Анализ (пробный / платный)

| Шаг | UX |
|-----|-----|
| Ссылка в чат | Одно живое сообщение прогресса |
| Готово | Альбом (2 фото) + разбор (1/5) с кнопками секций |
| Free | Секции 2–4 🔒, открыты «Главное» и «Идеи» |
| Paid | Все 5 секций + больше идей и постов |

---

### Этап 3 — Контент-воронка (конверсия)

```
Разбор → 💡 Идеи → ✍️ Пост 1/2/3 → Черновик
                                      │
                    ┌─────────────────┼─────────────────┐
                    ▼                 ▼                 ▼
              📤 Опубликовать    ✏️ Править      🔄 Другой вариант
                    │
                    ▼
              Preview → ✅ Опубликовать → ссылка на пост
```

**Счётчик пробного периода:** «Осталось N из 3 черновиков».

---

### Этап 4 — Paywall и подписка

**Триггер:** 4-й черновик или 🔒-секция разбора.

**Оффер:**
- 12 идей вместо 3
- 7 готовых постов
- все 5 разделов разбора
- безлимит публикаций в свой канал

**CTA:** `💳 Тарифы` → пакеты → Stars / оплата.

---

### Этап 5 — Retention

| Механика | Когда |
|----------|-------|
| **Мои отчёты** | Список: «Название канала · дата» → Открыть |
| Напоминание | Через 7 дней без активности (будущее) |
| Новый анализ | Ссылка в поле ввода из любого экрана |

## Мои отчёты (формат)

```
📁 Мои отчёты

1. «Название канала» · 10.07.2026 · пробный
2. «Другой канал» · 08.07.2026 · полный

Нажмите «Открыть» — вернётесь к разбору и идеям.
```

Кнопки: `Открыть` на каждый отчёт → `hist:open:{id}`.

## Модуль F — Антискам / модерация комментариев (в плане)

> **Статус:** ТЗ, фаза 2–3. Не блокирует MVP аналитики.

**Проблема:** в комментариях к постам канала — спам, фишинг, «перейди в личку», реклама конкурентов.

**Решение:** умный **инти-бот модератор** в составе Pulse AI:

| Компонент | Описание |
|-----------|----------|
| Мониторинг | Бот админ канала с правом удаления сообщений в связанной группе обсуждений |
| Классификация | LLM + правила: реклама, скам, крипто, «заработок», ссылки на сторонние каналы |
| Действия | Удаление, предупреждение автору, отчёт админу в ЛС |
| Обучение | Белый список админов, порог чувствительности, лог решений |
| Продукт | Отдельная опция в подписке «Защита комментариев» |

**Метрики успеха:** % удалённого спама без ложных срабатываний, время реакции < 30 сек.

**Зависимости:** бот админ канала + linked discussion group, таблица `moderation_events`, очередь на LLM.

## 1. Что это такое (одной фразой)

**Pulse AI** — Telegram-бот, который помогает **вести канал**:  
понять стиль → придумать посты → запланировать → **ловить заявки в комментариях** и подсказывать ответы.

Это **не** «ещё один ChatGPT в боте».  
Это **не** замена статистики Telegram (у админа и так есть свои графики).

**Обещание клиенту:** меньше рутины с контентом, больше заявок из комментов — **не выходя из Telegram**.

Бот в проде/локально: `@Pulsse_AI_bot` (название может чуть отличаться в конфиге).

## 2. Для кого

| Кто | Боль | За что платит |
|-----|------|----------------|
| Владелец / админ канала | «Не знаю что постить», лиды тонут в комментах | Контент + **Pulse Ассистент** |
| SMM / агентство | Много каналов, нужен стиль «как у них» | Пакеты разборов + ассистент |
| Мы сами (операторы) | Холодный поиск площадок, ЛС, парсинг чатов | Внутренние **скауты** (не продаём юзеру как отдельный продукт) |

## 3. Три столпа продукта (запомни эти три)

```
┌─────────────┐    ┌─────────────┐    ┌──────────────────┐
│  КОНТЕНТ    │ →  │   РИТМ      │ →  │   АССИСТЕНТ      │
│ анализ,     │    │ слоты, план │    │ лиды, ответы,    │
│ идеи, посты │    │ «что дальше»│    │ рассылка (квота) │
└─────────────┘    └─────────────┘    └──────────────────┘
```

1. **Контент** — кинул ссылку на канал → разбор → идеи → черновик поста / опрос.  
2. **Ритм** — слоты публикации в **часовом поясе юзера**, план, «следующий пост» без повторного ада.  
3. **Ассистент** — главная причина **подписки**: ловит лиды в комментах, черновик ответа, CRM, квота ЛС.

Метрики в боте — **вспомогательные** (для стиля и идей), не конкурируем с нативной статистикой TG.

## 4. Как устроена «кухня» (технарь на пальцах)

Две машины рядом:

| Часть | Что это | Порт (локально) | Зачем |
|-------|---------|-----------------|-------|
| **Java-бот** (Spring Boot) | Мозг продукта: меню, оплаты, контент, CRM | `:8081` | Всё, что видит юзер в Telegram |
| **Scout sidecar** (Python / Telethon) | Настоящие user-аккаунты TG | `:8090` | Join, парсинг, ЛС, кабинет переписки |
| **Веб-админка** | Панель оператора | `http://127.0.0.1:8081/admin/?token=…` | Скауты, прокси, чаты, ЦА |

```
Юзер в Telegram
      │
      ▼
 Java-бот  ──────►  БД (аккаунты, кампании, лиды, посты…)
      │
      │  HTTP
      ▼
 Scout sidecar  ──►  Telegram MTProto (через .session / tdata + прокси)
```

**Важно про скаутов:**  
карточка в админке ≠ «аккаунт живой».  
Живой = есть сессия + (лучше) свой прокси + бейдж **«В сети»**.  
`ACTIVE` в БД без Telegram = **не работает**, просто галочка.

## 5. Что уже сделано (сейчас можно трогать)

### 5.1. Ядро бота — контент

- Анализ **любого открытого** канала по ссылке / `@username` (без прав админа у бота).
- Посты, просмотры, реакции/репосты → ER, темы, топ/худшие, слоты «🔥».
- Подтягивание внешних метрик (TGStat / Telemetr / Telega) — где доступно.
- LLM-разбор: стиль, аудитория, просадки, **3 конкретных шага**.
- Идеи контента + черновики **под бриф разбора** (не рандомный бред).
- Фото к постам, укоротить текст, перегенерация.
- **Нативные опросы** в канал / обсуждения.
- Живой прогресс «бот не завис» (одно сообщение с этапами).

### 5.2. Ритм и кабинет

- Публикация сейчас / в слот.
- Слоты в **TZ юзера** (Кабинет → пояс), прошедшие часы скрыты.
- Меню: **Контент / Ассистент / Рост** + **⚙️ Кабинет** (канал, пояс, тарифы).
- «Аналитика+» в Росте — не второй дашборд вселенной.

### 5.3. Pulse Ассистент (inbound)

- Ловит лиды / возражения в комментариях (бот админ канала + есть обсуждения).
- Короткий живой черновик ответа.
- CRM лидов, follow-up ~24ч.
- Профиль компании / рамки ответов.
- Книга возражений, выводы после won/lost.

### 5.4. Деньги (биллинг)

**Пакеты разборов** (топливо контента):

| Пакет | Запросов | Цена |
|-------|----------|------|
| START | 10 | 890 ₽ |
| CONTENT | 18 | 1490 ₽ |
| PRO | 30 | 1990 ₽ |

**Подписка Pulse Ассистент** (главный продукт подписки):

|-------|------|-------|--------|---------|

Допы ЛС — **только при активной подписке**.  
Оплата Stars / пакеты — в коде; счётчики квот — живые.

Бонусы к пакетам (perk’и): разбор поста, жёсткий аудит, дайджест, конкурент, продающие посты и т.д. — часть live, часть в планах (см. §6).

### 5.5. Реклама / Radar (частично)

- Подбор площадок, карточка, **сделка** в боте (формат, +комиссия, креатив, бриф).
- Ad Radar: сигналы / quality score / дедуп (инфра есть).
- **Ещё нет:** полный эскроу, авто-ЛС админу площадки, ROI-трекер сделки.

### 5.6. Скауты + админка (операторка, наша кухня)

Это **внутренняя** машина роста Pulse, не фича «нажми кнопку» для клиента.

**Роли аккаунтов:**

| ID-диапазон | Роль | Что делает | ЛС |
|-------------|------|------------|-----|
| **1–99** (потом 1000+) | PARSER / OBSERVER | Join, парсинг ЦА, радар, смотреть чаты | **Нет** |
| **100–999** (потом 2000+) | SENDER / OUTREACH | Только исходящие ЛС | **Да** |
| Legacy `#33` | SENDER | Старый номер, живёт как есть | Да |

**Уже умеем в админке:**

- Обзор: sidecar online/offline, аккаунты, очередь, прокси.
- Прокси-пул: импорт `.txt`, проверка живых, 1 прокси = 1 акк, ротация при FLOOD.
- Карточки скаутов: создать, пауза/старт, SpamBot, прокси.
- Вход в TG: **tdata.zip** / `.session` / **auth_key + DC**; «Восстановить из secrets».
- Карточка идентичности как на лолзе: телефон, User ID, DC, хвост ключа, заметка — **даже если сессия сгорела**.
- Честный статус: **ACTIVE в БД** + отдельно **TG в сети / TG нет**. Старт без сессии — нельзя.
- **Кабинет TG** — UI как мессенджер: слева чаты, справа переписка, ответ, «прочитано».
- **ЦА / пул групп** — ссылки в общий пул (`scout_target_chats`); join **~1 / 30с**; enroll / **handoff** при сгорании PARSER/OBSERVER.
- Фильтр **Рабочие / Сгоревшие**, burn / wipe session / delete; audit дублей auth_key.
- SpamBot только у SENDER, **≤4/сутки**.
- Логи действий скаутов, шаблоны рассылки, кампании (код есть).

**Следующее (согласовано):** архив ЛС своих скаутов (ops-бэкап) — см. [HANDOFF](./HANDOFF.md) §7.

**Правило жизни скаута (выучено кровью):**  
один аккаунт = один sticky-прокси = **только sidecar**.  
Открыл тот же tdata в Desktop параллельно → Telegram жжёт ключ (`AuthKeyDuplicated`). Старый secrets после этого **мёртв**, нужен новый tdata с магазина.

## 6. Что в планах (ещё не «готово продавать»)

Грубо по приоритету:

| Когда | Что | Зачем |
|-------|-----|--------|
| Ближайшее | Дожать **outbound UX** в боте (кампании, понятные кнопки, счётчики) | Код рассылок есть, юзеру сыро |
| Ближайшее | Ad Intel / matchmaker / нормальный бриф админу площадки | Довести рекламный контур |
| Потом | Deal tracker + ROI рекламы | Видно, что сработало |
| Потом | Бенчмарки ниши в отчёте («у тебя vs ниша») | Умнее советы |
| Потом | News Intelligence (сюжеты дня + FactGuard) | Посты без галлюцинаций |
| Потом | Obsidian / штаб знаний | Операционка команды |
| Потом | Антиспам комментов, библиотека хитов, голос аудитории | Бонусы пакетов |
| Позже | Эскроу / выплаты по рекламе (комиссия ~20%) | Маркетплейс по-взрослому |
| Internal | Авто-скаут 24/7 на наших акках (dogfood) | Рост самого Pulse |
| Internal | **Архив ЛС скаутов** (текст → медиа) | Ops-бэкап; переживает burn сессии |

**Не путать:**  
публичный **канал бренда Pulse** (changelog, демо, кейсы) — это маркетинг и dogfooding.  
Холодные ЛС чужим админам — это **скауты**, внутренняя кухня.

## 7. Типичный путь пользователя (очень коротко)

1. Заходит в бота → кидает ссылку на канал.  
2. Получает разбор + идеи (бесплатно / с пакета).  
3. Делает пост / опрос → публикует или ставит в слот.  
4. Подключает бота админом → включается **Ассистент** на комментах.  
5. Платит подписку → квота ЛС / парсинг «своих» / «Найти ЦА» по тарифу.  
6. Рост: площадки, радар, доп. фичи — по мере готовности.

Оператор Pulse параллельно: админка → скауты → прокси → кабинет TG → кампании.

## 8. Чеклист «система живая?» (для нас)

1. Java на `:8081`, sidecar на `:8090` (`/health` → ok).  
2. В админке скаут: **TG в сети**, не только ACTIVE.  
3. PARSER: join 1–2 публичных группы → парсинг ЦА.  
4. SENDER: свой прокси → **1 тестовое ЛС** себе → лог ок.  
5. Кабинет TG: открыть диалог, ответить.  
6. Не логиниться этим же акком в Desktop.

Подробный операторский гайд: [SCOUT_OPS.md](./SCOUT_OPS.md).

## 9. Словарь (чтобы не путаться)

| Слово | Что значит |
|-------|------------|
| **Pulse AI** | Весь продукт |
| **Pulse Ассистент** | Подписка + агент в комментах / квоты (раньше путали с «Jarvis») |
| **Разбор / пакет** | Топливо: сколько раз можно проанализировать канал |
| **Скаут** | Наш user-аккаунт Telegram через sidecar |
| **Sidecar** | Python-сервис Telethon рядом с ботом |
| **tdata** | Папка сессии Telegram Desktop (грузим zip’ом) |
| **auth_key** | Ключ сессии с маркета (512 hex + DC) |
| **ЦА** | Целевая аудитория (участники чатов с @username + скор) |
| **Outbound** | Мы пишем людям первыми (ЛС) |
| **Inbound** | Люди пишут нам (комменты → лиды) |

## 11. Итог в трёх строках

1. **Клиенту** продаём: контент под канал + ритм + ассистента с заявками и квотами.  
2. **Себе** держим: скаутов, прокси, кабинет переписки, радар — чтобы продукт рос.  
3. **Дальше:** дожать рассылки в UX, рекламный контур, умные модули (ниши / новости) — не плодить второй «дашборд ради дашборда».

## Зачем канал, если есть бот?

| Канал (публичный) | Бот | Закрытый чат (будущее) |
|-------------------|-----|------------------------|
| Халява, акции, демо | Инструмент разбора | Подписка, обсуждения |
| Просмотры = реклама себе | Конверсия в пакеты | Ретеншн |
| «Попробуй бесплатно» | Полный продукт | Комьюнити |

**Бот не заменяет админа** — он снимает рутину: черновики, аналитика, идеи. Человек утверждает и публикует (или авто по расписанию позже).

## Live vs async — как адаптировать

Live-каналы (стрим, «доброе утро с камеры») **не переносятся 1:1**. В async-канале Pulse AI:

| Live-паттерн | Async-аналог в Pulse AI |
|--------------|-------------------------|
| Доброе утро на камере | ☀️ **Утренний бриф** — 3 пункта «что проверить в канале сегодня» |
| Новость дня в эфире | 📰 **День в TG** — тренд/инсайт (только проверенные источники) |
| Тренировка / погода | ❌ не наш формат — только если ниша канала про это |
| Реакция на события | 📋 **Changelog** / ⚡ **Фича бота** |

## Саморазвитие системы (не дообучение LLM)

1. **Реестр релизов** (`product_releases`) — факты апдейтов. Changelog собирается из них (формат патчноута), LLM не выдумывает фичи.
2. **Референс-каналы** (`pulse.product.reference-channels`) — бот скрейпит посты → LLM выжимает стиль → `product_style_snapshots`.
3. **Проверенные источники** (`product_trusted_sources`) — для новостей; без источника = инсайт, не выдуманный факт.
4. **Dogfooding** — каждый пост в канале = тест промптов и форматирования.

## Сюжет канала

`/product` → **📖 Сюжет канала**:
1. **Собрать сюжетный план** — 6 эпизодов (боль → обещание → ритуал → ассистент → рост → приглашение)
2. Посмотреть план
3. **Опубликовать следующий** — вручную по одному
4. **Запустить арку** — эпизод 1 сейчас, остальные по одному в день в 11:00 МСК

Это не «мы ахуенные» одним постом, а сериал знакомства с продуктом (без раскрытия схем).

## Настройка канала 4338331508

1. Добавьте `@Pulsse_AI_bot` **админом** с правом **публикации**.
2. В `application-local.yaml`:
   ```yaml
   pulse.product:
     enabled: true
     channel-chat-id: -1004338331508
     owner-telegram-ids: [ВАШ_ID]  # @userinfobot
     reference-channels:
       - telegram
       - имя_канала_в_нише
   ```
3. Перезапустите бота → `/product` → «🔄 Учиться с каналов» → выберите рубрику → опубликуйте.

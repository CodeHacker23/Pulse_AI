# Рекламный посредник Pulse (Module C) — учли / не учли

Цель продукта: пользователь видит **тематические площадки** под свой канал/ЦА,
берёт креатив, бронирует размещение **через нас**, мы берём **~20%** сверху цены админа.

## Реальный мир сделки (из практики с админами)

Типичный ручной цикл:
1. Нашли канал → написали админу.
2. Уточнили: цена, формат (пост / 1ч закреп / 24ч / без), что можно в тексте, слот.
3. Админ может отказать (не по тематике, нет мест, «только натив»).
4. Согласовали креатив.
5. **Сначала перевод админу**, потом пост в оговорённое время.
6. Иногда правки после модерации, перенос слота, «не вышло — вернём».

Риски посредника: админ взял деньги и пропал; пост вышел не в том виде; рекламодатель
хочет рефанд; спор «кто виноват»; KYC/налоги при потоке платежей.

## Что уже есть в коде (симбиоз данных)

| Данные | Где | Зачем для рекламы |
|--------|-----|-------------------|
| Разбор канала, категория, стиль | `channels`, `channel_profile_snapshots`, `content_style_prompt` | ниша + тон креатива |
| FAQ / возражения | `sales_faq`, `sales_objections` | оффер в рекламном посте |
| Скоринг площадки | `ad_placements` + `AdPlacementQualityService` | живой/мёртвый/спам, avg views, ad ratio |
| Подбор по нише | `AdPlacementMatchService` | TGStat peers + база разборов Pulse |
| Креатив | `AdDealService.generateCreative` | черновик под площадку |
| Интерес к сделке | `ad_deals` (INTEREST/BRIEF…) | каркас воронки |
| Сигналы прайсов | watches + observer hits | разведка, не инвентарь |

Анализ чужого канала по ссылке = **крючок** (идеи). Публикация только если бот **админ**
в канале рекламодателя (не в площадке).

## Что сделано в этом срезе UX

- Меню «Площадки для рекламы» вместо непонятного Ad Radar.
- «Подобрать под нишу», карточка площадки, креатив, «интерес к размещению».
- Явно: комиссия 20%, эскроу — следующий этап.

## Что ещё не автоматизировано (критично для денег)

| Этап | Статус | Нужно |
|------|--------|--------|
| Прайс-лист площадки (пост/1ч/24ч) | ❌ | карточка оффера от админа или Telega/парсинг |
| Переписка с админом площадки | ❌ | scout SENDER / шаблоны + эскалация человеку |
| Оплата клиентом | ❌ | Stars / карта / счёт; чек |
| Эскроу → выплата админу | ❌ | холд до подтверждения `message_id` поста |
| Модерация креатива админом | ❌ | статус REJECTED / правки |
| Закреп-таймеры | ❌ | напоминание снять через 1ч/24ч |
| Споры / рефанды | ❌ | политика + ручной кабинет оператора |
| Юр. рамка (агент / оферта) | ❌ | договор-оферта двум сторонам |

## Модель цены (зафиксировали)

```
price_client = price_admin × (1 + 0.20)
```

Клиент видит только `price_client`. Админ получает `price_admin` после LIVE.
Pulse удерживает разницу. Варианты сложнее (фикс + %, min fee) — позже.

## Рекомендуемые статусы `ad_deals`

`INTEREST` → `BRIEF` → `AWAITING_ADMIN` → `AGREED` → `PAID` → `LIVE` → `DONE`  
ветки: `REJECTED`, `DISPUTE`, `REFUNDED`.

## Симбиоз с остальным Pulse

1. **Контент** кормит нишу и стиль → лучший матч и креатив.
2. **Ассистент** (FAQ) кормит оффер в рекламном посте.
3. **Рост / площадки** тратят этот контекст на закупку трафика.
4. Каждый ручной `resolveForComparison` / разбор чужого канала **обогащает** базу ниш.

## Диалог с админом площадки — как задумано vs сейчас

**Сейчас в боте (срез сделок):**
1. Поиск площадки → **Оформить сделку**
2. Выбор формата: пост / +1ч закреп / +24ч закреп
3. Цены: ориентир админу + **вам +20%**
4. Креатив → **Бриф админу** (текст для копирования в ЛС)
5. «Отправил админу» → статус `AWAITING_ADMIN`
6. Внести цену админа / Согласовано / Отказ → `AGREED` / `REJECTED`

Авто-ЛС админу через scout и эскроу-оплата — **ещё нет**.

**Цель (автопосредник):**
1. Pulse (scout SENDER / шаблон) пишет админу площадки: формат, слот, цена.
2. Админ отвечает → бот парсит цену/условия → статус `AWAITING_ADMIN` → `AGREED`.
3. Клиенту показывают `price_admin × 1.20`.
4. Оплата клиентом нам → холд → после LIVE выплата админу `price_admin`.
5. Отказ по тематике → `REJECTED`, креатив правим или ищем другую площадку.
